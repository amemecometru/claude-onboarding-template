# Microsoft 365 Copilot Onboarding Template

This folder contains a platform-specific, enterprise-oriented onboarding and rollout template for Microsoft 365 Copilot. It is designed as a **working portfolio artifact**: it describes a disciplined approach, but does not claim that a client tenant has been configured or that enterprise outcomes have been achieved.

## Files in this template

1. [`01-enterprise-rollout-runbook.md`](01-enterprise-rollout-runbook.md) — gated lifecycle from intake and readiness through pilot, expansion, and operations.
2. [`02-readiness-and-governance.md`](02-readiness-and-governance.md) — readiness checks, control ownership, and decision record.
3. [`03-pilot-measurement-pack.md`](03-pilot-measurement-pack.md) — baseline, scenario test log, pilot metrics, and 30/60/90-day decision gates.
4. [`04-end-user-onboarding.md`](04-end-user-onboarding.md) — participant-facing orientation, safe-use guidance, and feedback.
5. [`05-platform-operations-runbook.md`](05-platform-operations-runbook.md) — operational roles, support, change, access, and maintenance.
6. [`06-source-register.md`](06-source-register.md) — official Microsoft references and claims to verify before delivery.

## How to use

- Start with the rollout runbook; do not jump directly to user training or broad license assignment.
- Complete readiness and governance with the client’s authorized owners. The template is not a substitute for tenant administration, security review, legal advice, or client policy.
- Agree on pilot scope, measures, thresholds, privacy boundaries, and decision-makers **before** the pilot begins.
- Tailor examples to approved, low-risk work scenarios. Never put confidential, personal, regulated, or proprietary data into a demonstration unless the client explicitly authorizes that environment and use.
- Mark tenant-specific values and unresolved decisions. Do not present placeholders as completed configuration.
- Review the source register against current Microsoft documentation. Features, licensing, names, admin experiences, and availability can change by tenant, plan, region, and release.

## Labels used in the files

- **[Client decision]** — the client’s accountable owner must decide and document this.
- **[Tenant verification]** — verify in the specific tenant and record evidence; do not assume it is enabled or available.
- **[Fill in]** — complete before using the artifact with a client.
- **Gate** — do not proceed until the named decision-makers review the evidence and record go/no-go.

## Scope and honest attribution

This is a self-directed portfolio template informed by Microsoft’s public guidance. It is not Microsoft or Deloitte material, does not confer Microsoft certification, and does not establish that the author has delivered an enterprise rollout. Any pilot results must be reported with the actual participants, dates, methods, limitations, and permission to share.
