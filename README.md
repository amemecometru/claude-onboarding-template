# AI onboarding templates — working repository

This repository is a **working collection** of separate, platform-specific onboarding templates. Each template has its own directory; do not assume that instructions, skills, settings, or deployment steps transfer between products.

## Template directory map

- **Claude:** [`claude-team-onboarding/`](../claude-onboarding-template/tree/main/claude-team-onboarding) and [`docs/`](../claude-onboarding-template/tree/main/docs) — existing Claude materials.
- **Microsoft 365 Copilot:** [`microsoft-365-copilot/`](microsoft-365-copilot/README.md) — enterprise-oriented rollout, readiness, measurement, end-user onboarding, operations, and verification sources.
- **Gemini:** not included in this working set yet.

The Microsoft 365 Copilot folder is a **portfolio template**, not a claim of completed client deployment, tenant configuration, or measured enterprise results. Items marked `[Client decision]`, `[Tenant verification]`, or `[Fill in]` require client-specific decisions or validation. Verify changing product details against the linked Microsoft documentation before use.
